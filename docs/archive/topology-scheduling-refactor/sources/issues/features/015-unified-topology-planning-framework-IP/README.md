# Feature 015：统一拓扑调度重构

本目录统一承载拓扑调度重构的需求、上游分析、设计、历史原型及验证记录。当前目标方案处于设计阶段，issue 保持 `IP`。

## 重构主旨

**把拓扑规则融入统一的节点调度，让拓扑偏好和普通节点偏好共同决定 Pod 的放置。**

整体过程是：

**硬约束圈定可选节点 → 所有软偏好统一评分 → 为整组 Pod 生成放置方案**

- **硬约束决定“能放在哪里”**：根据资源、拓扑和其他必要条件，确定并维护合法的节点范围。
- **软偏好决定“更希望放在哪里”**：将拓扑偏好转化为节点候选分，与 NodeAffinity、Binpack 等评分共同参与选择。
- **统一规划决定“整组怎么放更合适”**：考虑多个 Pod/SubGroup 之间的影响，必要时调整前面的选择，并比较完整布局的综合收益。

HyperNode 继续用于描述拓扑结构、成员和层级关系；节点选择与整组放置由统一调度框架完成。各个场景的实现细节围绕约束表达、评分组合和放置调整展开。
